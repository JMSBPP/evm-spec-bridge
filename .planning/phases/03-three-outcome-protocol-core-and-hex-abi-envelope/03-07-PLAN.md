  <teaching>
    The 45 s test PASSED for one reason: the call site ignored `success`. Everything else about that
    run was fine. So the fix is not a timeout and not a retry — it is that there must be no way to
    reach the end of the call site without having produced a verdict.

    03-CONTEXT rejected the alternative that looks tidier: catching the revert and re-surfacing it as
    a typed third outcome in Solidity. It would make the three outcomes uniform on both sides, and it
    would create a path where an unreachable oracle is a VALUE. A value can be logged, counted,
    defaulted, or skipped by the next person. A revert cannot.
  </teaching>
  <action>
    In `solidity/src/SpecOracle.sol` add:

      function requireOutcome(string memory method, string memory params)
        internal returns (uint8 tag, bytes memory body)
      {
        (bool ok, bytes memory ret) = callOracle(method, params);
        require(ok, "oracle transport failure");        // INTEG-05: unconditional, no catch
        bytes memory payload = abi.decode(ret, (bytes));
        uint16 version;
        (version, tag, body) = abi.decode(payload, (uint16, uint8, bytes));
        require(version == PROTOCOL_VERSION, "protocol version");
        require(tag == TAG_SUCCESS || tag == TAG_REJECTION || tag == TAG_FAULT, "unknown tag");
      }

    Every `require` is on the ONLY path out. There is no early `return`, no `if (!ok) return;`, no
    `try`/`catch`. A caller that ignores the return values still cannot reach the next statement
    unless the oracle answered with a well-formed, correctly-versioned, known-tag envelope.

    Write `solidity/test/WedgeRed.t.sol` with exactly one test:

      function test_wedgedOracleIsRed() public {
        (uint8 tag, ) = requireOutcome("spec_probe", "[]");
        require(tag == TAG_SUCCESS, "expected success");
      }

    `scripts/wedge-red-test.sh` is the thing that asserts the failure. A test whose red is the
    deliverable must say so, or a future reader will "fix" it.

    Add to `solidity/src/SpecOracle.sol` a comment recording that Phase 9's GEN-04 generates this
    exact shape, so asserting on success becomes structural rather than disciplinary.
  </action>
